# 任务简报模板

复制本文件为 `prompts/{product-or-scene}-{action}.md`，填完再写提示词本体。
花括号 `{name}` 是占位符，方括号是可选。

---

## 元信息

- **ID**: `prompt.{product}.{action}` 例如 `prompt.support.triage`
- **版本**: `v0.1`
- **状态**: `draft` — `draft` | `review` | `prod` | `frozen`
- **产品 / 场景**:
- **拥有者**: `@name`（产品） / `@name`（工程）
- **模型**: `应用的模型 ID`
- **评估集**: `evals/{dir}/`
- **上线时间**: `空` 或 `YYYY-MM-DD`

## 目标

用一句话写清楚这次调模型**要完成什么**，不要写「帮助用户」。

- 目标：
- 成功样例（人能看懂的 1 句）：
- 失败样例（一定不能出现的 1 句）：

## 约束

写成检查清单。模型违反任一条即为评估失败。

- [ ] 语言：简体中文，用户用英文则跟英文
- [ ] 不要猜测缺失字段；缺了就问或标 `unknown`
- [ ] 不要编造链接、ID、价格、法规依据
- [ ] 不要越权调用工具（工具清单见角色规范）
- [ ] 涉及发布 / 删除 / 对外发消 → 停下请人确认
- [ ] 其他：

## 输入

模型实际会收到什么。每项写清源、是否必填、格式。

| 字段 | 来源 | 必填 | 格式 / 示例 |
| --- | --- | --- | --- |
| `例如 user_message` | 用户 | 是 | 纯文本 |
| `例如 ticket_id` | 系统 | 是 | `TCK-12345` |
| `例如 retrieved_docs` | RAG | 否 | Markdown 片段列表 |

上下文窗口：最近 N 轮 / 不带历史。
敏感信息：不要把 `__` 贴进提示词。

## 完成条件（Done when）

全部满足才算这次调用完成。能自动检就写自动检，不能的写人工抽查。

- [ ] 输出符合约定格式（见下）
- [ ] 每个必填字段都有值或明确标 `unknown`
- [ ] 没有调用约束外的工具
- [ ] 评估集本次回归过线：`evals/{dir}/` 通过率 ≥ __%
- [ ] 其他：

### 输出格式

```text
在这里贴 schema / Markdown 节点 / 固定字段。
例如：
{
  "category": "billing | bug | feature | other",
  "priority": "p0 | p1 | p2",
  "reply": "string",
  "need_human": true
}
```

明确写出模型**不该做**的事。审查时用来打回「顺手加功能」。

- 不要：
- 不要：
- 超出边界时的行为：拒绝并说明原因 / 转给人 / 返回固定错误码

## 提示词本体

```text
只贴会发给模型的文字。不要写给人看的注释。
```
