# 示例

这里只放**可以整套拷贝的完整示例**：一个场景 + 简报 + 角色规范 + 至少 3 条评估用例。

不要放：

- 碎片提示词（应该在 `prompts/`）
- 单条 eval（应该在 `evals/`）
- 教程性博客文

## 目录约定

```text
examples/{example-id}/
  README.md          # 场景说明、如何拷贝
  brief.md           # 填好的任务简报
  role.md            # 填好的角色规范（若有 Agent）
  evals/             # 至少 golden × 2 + failure × 1
```

每个示例自成一个小目录，不要把多个产品挤在一起。
